--- layout: default title: Gemini Nano description: Make Chrome's built-in model work with Vianney, or find out why it does not download. ---

Vianney can ask Chrome's own model, Gemini Nano, for a second opinion when its word lists and its local model Kev-0.6B are unsure. It is optional, and it needs Google Chrome on a computer. This page checks your browser, says what is missing, and shows where Chrome tells you why the model does not come. The checks run in this page and send nothing anywhere.

This browser
    What has to be true
    {% include icon.html name="check" size=14 %}
    Google Chrome {{ site.data.nano.minChrome }} or newer, on a computerWindows, macOS, Linux or a Chromebook Plus. Not Chromium (the build that Linux distributions ship leaves the model out), not Firefox, not a phone.
    {% include icon.html name="check" size=14 %}
    About 20 GiB free on the drive of the browser profileChrome's documentation says 22 GB. Below that Chrome does not start the download, and says nothing about it.
    {% include icon.html name="check" size=14 %}
    A graphics chip with more than 4 GB of video memory, or 16 GB of memory and 4 coresA page cannot read the video memory: the diagnostics page of Chrome, below, says whether Chrome accepts the computer.
    {% include icon.html name="check" size=14 %}
    The switch “On-device AI” is onIn AI settings, Google Chrome only. When it is off, Chrome never downloads the model.
    {% include icon.html name="check" size=14 %}
    No flag has to be changed in Chrome 154 and newerThe Prompt API is on by default there. Older versions are listed under Flags.
    Where Chrome says why
    1
    {{ site.data.nano.pages.chromeUrls }}Since Chrome 158 the diagnostics page is hidden until you press “Enable internal debugging pages” here. Once.
    2
    {{ site.data.nano.pages.internals }}Open “Broker State”. Its lines say, one by one, why the model is or is not there (see below).
    3
    {{ site.data.nano.pages.aiSettings }}The switch “On-device AI”. It exists in Google Chrome only.
    4
    {{ site.data.nano.pages.components }}“Optimization Guide On DeviceModels Manifest”: press Check for update, then restart the browser.
    5
    {{ site.data.nano.pages.policy }}On a managed computer, the policy GenAILocalFoundationalModelSettings can forbid the model.

    None of these has to be changed in Chrome 154 and newer: the Prompt API is on by default, and the flag that skipped the hardware check, #optimization-guide-on-device-model, is gone. A flag that is listed for your version is worth setting only if the checks above say that the interface is missing.

    This page and the extension

    A web page cannot open a page of Chrome: the browser refuses a link, window.open and location alike. So the addresses above are copied. When Vianney is installed in the same browser, this page finds it and asks it to open them, and the checks also use what only an extension can see, such as the free disk space.
