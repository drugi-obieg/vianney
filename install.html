Install the test build

Version {{ site.data.release.version }}, released {{ site.data.release.date }}, {{ site.data.release.kilobytes }} KB. This is a build for testing. It is meant for desktop Chrome, Edge and Brave, version 138 or newer. It is not in any browser store, so it is installed by hand, which takes about a minute.

Download version {{ site.data.release.version }} (zip)

SHA-256 of the zip: {{ site.data.release.sha256 }}
To check it on a Mac or Linux machine, run shasum -a 256 {{ site.data.release.latest }} in the folder you downloaded it to.

Steps

  1. Unzip the download. You get one folder, {{ site.data.release.folder }}. Keep it where it is: the browser loads the extension from that folder, so moving or deleting it removes the extension.
  2. Open chrome://extensions (Brave: brave://extensions, Edge: edge://extensions) and switch on Developer mode.
  3. Click Load unpacked and choose the unzipped folder, the one that contains manifest.json.
  4. The settings page opens by itself. Pin the extension from the puzzle-piece menu if you want its icon in the toolbar.

First things to try

  • Search YouTube for something you expect a rule to catch. Matching cards disappear, the icon shows how many were hidden on this page, and the Log section of the settings explains each one.
  • Move a rule's slider. The page updates at once, in both directions.
  • Paste a title or a few subtitle lines into the Test box to see which rules react and how confident each one is.
  • Set the break reminder to 1 minute, play any video for that long, and look for the card in the list.
  • Experimental, and only if your Chrome offers the model with picture and sound input: the Pictures and sound section of the settings. It is off until you switch it on, and every part of it has its own switch, a slider per rule, and allow and block lists that always win.

What it does, and what it does not

  • It runs only on www.youtube.com. The extension's details page in Chrome lists that site access, which is how it hides cards and reads subtitles.
  • Its only other permission is storage, for your settings and the log. It has no account, analytics or telemetry, and your settings and watch time stay in your browser; removing the extension deletes them. It makes no network requests of its own, with one exception: if you switch on the experimental picture check, its background worker fetches the thumbnail of each video from YouTube's image server (i.ytimg.com), the same pictures the page shows, to give them to Chrome's on-device model. Nothing is sent anywhere else.
  • Subtitles are read from YouTube's own player request, never fetched separately.
  • Chrome's built-in AI model is optional and off until you download it from the settings page. Without it, the rules work from their word lists. The picture and sound checks need the same model with picture and sound input, which many computers do not get.

Known limits of this build

  • Subtitle filtering needs YouTube to give the player the caption text. In a test with an anonymous browser it did not, so this part has not been seen working on a real, trusted session. The settings page says what happened to the captions of the last video you watched.
  • The rules are drafts. The word lists and the percentages on the sliders are placeholders until they are measured on a labelled set of examples.
  • The picture and sound checks have only been run with a stand-in for Chrome's model, because the model could not run on the test machine. The whole path was seen working (thumbnails fetched, sound recorded from a playing video, hiding, blurring, muting, pausing, lists), but how well the real model recognises anything, and how fast it is, is not known yet. Expect false alarms and misses, and expect it to be slow. A sound check can only react after a few seconds of sound have played.
  • It was tested in Chrome 158. Edge and Brave are built on the same engine and should behave the same, but they have not been tried.
  • There are no automatic updates. To update, download the new zip, replace the folder, and press the reload arrow on the extension's card.

Source and problems

The source, the plan and the issue tracker are on GitHub. The extension is plain JavaScript with no build step, so what you load is exactly what is in the extension folder of the repository.
